# UTS Pemrograman Web - Laravel MVC

Website **Sistem Manajemen Inventaris Barang** sederhana yang dibikin pakai Laravel (MVC) murni tanpa database buat tugas UTS Pemrograman Web.

## Tentang Web Ini
Aplikasi ini dipakai buat mengelola data barang secara statis menggunakan array di controller. Ada fitur login sederhana, halaman dashboard, tabel data barang, sampai halaman profil. Semuanya dibalut pakai desain kustom Tailwind CSS bertema *Dark Neon* dan *Asymmetrical Layout*.
